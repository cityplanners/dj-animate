# Chat → layers → scene link

The normal website opens with the original GTA storefront, Pendragon sprite,
ground shadow and Backseat demo. Chat imports are optional: only an explicit
scene/manifest parameter or scene fragment loads another illustration. Opening
the plain website URL again returns to the original GTA scene. Prepared scenes
add assets under their own folders; they do not replace the homepage sprites.

Say **dj-animate it** with an image. The preparation workflow extracts a clean
background, transparent character sprites and separate props/light overlays,
packages their positions and audio routes, publishes the assets, and returns a
link that opens the prepared scene in the studio. Image extraction happens
during preparation with ChatGPT image tools; the static page loads these assets.
Music decoding and animation run in the browser. Press Play after opening the
link; browsers require a gesture before playing audio.

## Link formats

| Link | Purpose |
| --- | --- |
| `?scene=first-order` | Load `scenes/first-order/scene.djscene.json` and its assets. |
| `?manifest=https%3A%2F%2Fexample.com%2Fscene.djscene.json` | Open a published, CORS-enabled external manifest. |
| `?scene=first-order&preset=warp&master=0.4&start=1&duration=3` | Override the effect mix and selected video range. |
| `?scene=first-order&yt=<encoded YouTube URL>` | Open prepared layers with the chosen YouTube player. |
| `#scene=<base64url JSON>` | Reopen hosted assets with edited layer positions, routes and settings; generated by Copy scene link. |

Optional query values: `preset` (`sunset`, `clean`, `fever`, `warp`), `master`
(0–1.5), `gain` (0–2), `response` (0.55, 1, 1.8), `start`, `end`, `duration`
(seconds). Explicit `end` takes precedence over `duration`. Ranges clamp to the
loaded track. A manifest with `audio: null` uses the bundled Backseat sample.

Paste a video URL into **Or paste a YouTube link**, then click **Use YouTube**.
Watch links, youtu.be links, Shorts, mobile and Music links are accepted, including
timestamps. The player stays visible and retains its standard controls. The
studio's play/pause/seek and selection use the YouTube clock. No API key or server
is required. YouTube may reject private, removed or embedding-disabled videos.

For real music-driven motion and video export, click **Connect tab audio** in a
desktop browser that supports tab audio sharing, select this studio tab, and
enable **Share tab audio**. The four filters measure that stream, and its audio
is included in exports. Only the generated scene canvas is recorded as video;
the shared tab's video frames are not read or added to the export. Stop sharing
with the same button or the browser's sharing control. Sharing has to be granted
again after reopening a scene. Before connection, the graph is empty and export
is disabled; it never substitutes Backseat measurements for the YouTube track.

On browsers without tab-audio capture, including typical mobile browsers, the
link can play but full analysis/export requires loading an audio/video file.
Live measurements cover only portions listened to, not an analysis of the full
YouTube video. Clips use the first 30 minutes. Export runs in real time, so
buffering, playback rate and device speed affect its wall-clock length. Ordinary
uploads still use full offline analysis and require no sharing permission.

Save a YouTube reference as `"audio": {"source":"youtube", "url":"https://youtu.be/VIDEO_ID"}`.
Projects and Copy scene link keep that reference and clip range. A `yt` (or
`youtube`) query parameter can also set the source. Existing YouTube `t`/`start`
timestamps supply the initial selection; explicit studio `start`, `end` and
`duration` query values take precedence. An offline scene bundle requires a
local music file; YouTube playback needs a hosted HTTPS page and internet.

References: [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference),
[browser screen/audio sharing](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia).

No image bytes or temporary chat download URLs go into a scene link. All
referenced files must remain reachable. Link recipients can access published
scene assets. Local uploads stay local; use Save project for an embedded file
or deliberately publish the prepared scene to make a shareable link. A fragment
is URL encoding, not encryption. External hosts must allow anonymous CORS reads
for images, JSON and music so both preview and export remain usable.

## Prepare and publish

1. Extract the clean background and transparent sprites before animating.
   Preserve the source illustration alongside generated derivatives. Inspect
   alpha, lettering, layout, missing background areas, and sprite alignment.
2. Put the assets and `scene.json` in one directory. Set positions from the
   source scene, using a matching canvas aspect ratio. Keep meaningful pieces
   separate; retain a single object when splitting it would break alignment.
3. Run `npm run scene:pack -- path/to/scene.json --id my-scene` from this repo.
   `--base https://cityplanners.github.io/dj-animate/` selects the Pages hostname.
   The command validates the manifest and copies local assets into
   `web/scenes/my-scene/`. It never pushes. Existing IDs require `--replace`.
4. Run `npm test` and `npm run build`; open `?scene=my-scene` and verify loading,
   layer controls, playback and export. Commit and push the prepared scene and
   any app changes to `main`. Wait for the Pages deployment to succeed and
   verify the published URL before returning it.

The manifest is a version 1 dj-animate project. Use `src` for hosted/relative
assets; Save project embeds `data` for local reopening. Canvas width/height,
layer transforms, visibility, effects, clip range, and audio routes are retained.
Sprite x is its horizontal center, y is its bottom, in percent of the canvas.
Sprite scale 1 means 93% of canvas height; backgrounds use a centered cover fit.
Layer `blend` is `source-over`, `screen` or `lighter`. `band` 0–3 chooses bass,
low mids, upper mids or highs; `pulse` 0–0.1 scales the layer and `flicker` 0–0.3
modulates opacity from that smoothed band's energy. `motion: false` disables
layer motion. Avoid strong whole-scene motion when poster lettering must stay
readable. See `web/scenes/first-order/scene.djscene.json` for a complete example.

The standard hostname is `https://dj.cityplanners.co/`; the fallback is
`https://cityplanners.github.io/dj-animate/`. The same relative manifests work
on either hostname. Verify which host responds before delivering a link.

## VEHICLE objects

Select a car sprite, set **Layer type → VEHICLE**, and load a rough Wavefront
`.obj`, or use the built-in convertible proxy. The **Vehicle view** selector
switches between the illustration, shaded model and OBJ wireframe. Travel,
spring stiffness and damping control the suspension; each of the four wheels
has its own music-band selector. Bands measure frequencies, rather than
isolating named instruments. Zero travel or **Animate this layer** off holds
the vehicle at rest. The same renderer is used for preview and video export.

Prepared scenes use `role: "vehicle"` and a `vehicle` object:

```json
{
  "model": "convertible.obj",
  "view": "sprite",
  "travel": 0.22,
  "stiffness": 95,
  "damping": 11,
  "wheelBands": [0, 1, 2, 3],
  "wheelGains": [1, 1, 1, 1],
  "wheels": [
    {"id": "fl", "x": 0.594, "y": 0.8, "rx": 0.064, "ry": 0.185},
    {"id": "rl", "x": 0.17, "y": 0.6, "rx": 0.043, "ry": 0.148}
  ]
}
```

OBJ axes are X toward the nose, Y up and Z toward the right side. Give tyre
meshes the groups `wheel_fl`, `wheel_fr`, `wheel_rl`, `wheel_rr`; other groups
move with the chassis. The four damped springs drive heave, pitch and roll.
The illustrated view projects its texture in depth and can separate visible
tyres using normalized ellipse coordinates in `wheels`. Hidden wheels still
have independent springs. A single illustration supplies only one view; the
rough shaded model is available to inspect the complete 3D geometry.

The packer copies `.obj` assets alongside images. Copy scene link retains
hosted model URLs and suspension settings. Save project and offline scene
bundles embed OBJ text; a locally uploaded model requires Save project.
External material files are ignored. Models are bounded to 2 MB, 20,000
vertices and 40,000 triangles. Suspension resets when seeking or looping.

Other sprites may use `sway: {"amount": 4, "rate": 0.6, "band": 1}` for
music-driven wind with a pinned top and moving hem. `blend: "multiply"` supports
shadow overlays. Optional `alphaCutoff` removes low-alpha extraction halos at
render time while preserving the original asset. `clip` is a normalized polygon
for foreground occlusion, such as a hand over a separate poncho.
