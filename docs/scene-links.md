# Chat → layers → scene link

The normal website opens with the original GTA storefront, Pendragon sprite,
ground shadow and Backseat demo. Chat imports are optional: only an explicit
scene/manifest parameter or scene fragment loads another illustration. Opening
the plain website URL again returns to the original GTA scene. Prepared scenes
add assets under their own folders; they do not replace the homepage sprites.

Say **dj-animate it** with an image. The preparation workflow extracts a clean
background, transparent character sprites and separate props/light overlays,
packages their positions and audio routes, publishes the assets, and returns a
link that opens the prepared scene in the studio. Image extraction happens
during preparation with ChatGPT image tools; the static page loads these assets.
Music decoding and animation run in the browser. Press Play after opening the
link; browsers require a gesture before playing audio.

## Link formats

| Link | Purpose |
| --- | --- |
| `?scene=first-order` | Load `scenes/first-order/scene.djscene.json` and its assets. |
| `?manifest=https%3A%2F%2Fexample.com%2Fscene.djscene.json` | Open a published, CORS-enabled external manifest. |
| `?scene=first-order&preset=warp&master=0.4&start=1&duration=3` | Override the effect mix and selected video range. |
| `#scene=<base64url JSON>` | Reopen hosted assets with edited layer positions, routes and settings; generated by Copy scene link. |

Optional query values: `preset` (`sunset`, `clean`, `fever`, `warp`), `master`
(0–1.5), `gain` (0–2), `response` (0.55, 1, 1.8), `start`, `end`, `duration`
(seconds). Explicit `end` takes precedence over `duration`. Ranges clamp to the
loaded track. A manifest with `audio: null` uses the bundled Backseat sample.

No image bytes or temporary chat download URLs go into a scene link. All
referenced files must remain reachable. Link recipients can access published
scene assets. Local uploads stay local; use Save project for an embedded file
or deliberately publish the prepared scene to make a shareable link. A fragment
is URL encoding, not encryption. External hosts must allow anonymous CORS reads
for images, JSON and music so both preview and export remain usable.

## Prepare and publish

1. Extract the clean background and transparent sprites before animating.
   Preserve the source illustration alongside generated derivatives. Inspect
   alpha, lettering, layout, missing background areas, and sprite alignment.
2. Put the assets and `scene.json` in one directory. Set positions from the
   source scene, using a matching canvas aspect ratio. Keep meaningful pieces
   separate; retain a single object when splitting it would break alignment.
3. Run `npm run scene:pack -- path/to/scene.json --id my-scene` from this repo.
   `--base https://cityplanners.github.io/dj-animate/` selects the Pages hostname.
   The command validates the manifest and copies local assets into
   `web/scenes/my-scene/`. It never pushes. Existing IDs require `--replace`.
4. Run `npm test` and `npm run build`; open `?scene=my-scene` and verify loading,
   layer controls, playback and export. Commit and push the prepared scene and
   any app changes to `main`. Wait for the Pages deployment to succeed and
   verify the published URL before returning it.

The manifest is a version 1 dj-animate project. Use `src` for hosted/relative
assets; Save project embeds `data` for local reopening. Canvas width/height,
layer transforms, visibility, effects, clip range, and audio routes are retained.
Sprite x is its horizontal center, y is its bottom, in percent of the canvas.
Sprite scale 1 means 93% of canvas height; backgrounds use a centered cover fit.
Layer `blend` is `source-over`, `screen` or `lighter`. `band` 0–3 chooses bass,
low mids, upper mids or highs; `pulse` 0–0.1 scales the layer and `flicker` 0–0.3
modulates opacity from that smoothed band's energy. `motion: false` disables
layer motion. Avoid strong whole-scene motion when poster lettering must stay
readable. See `web/scenes/first-order/scene.djscene.json` for a complete example.

The standard hostname is `https://dj.cityplanners.co/`; the fallback is
`https://cityplanners.github.io/dj-animate/`. The same relative manifests work
on either hostname. Verify which host responds before delivering a link.
